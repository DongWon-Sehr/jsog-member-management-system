# 주삼오공 (운동인증방) 관리 시스템 기능 명세서 (V1.3.0)

## 1. 개요
- **목적**: 온라인 운동인증 모임 회원 및 인증현황 관리, 카카오 챗봇 연동 자동화
- **플랫폼**: Google Workspace (Google Sheets + Google Apps Script).
- **접근 권한**: 관리자 (Google 계정 기반 인증 예정)

## 2. 기술 스택
- **FE**: Vue.js 3 (Composition API), Tailwind CSS, Phosphor Icons, **Element Plus**, **Chart.js**.
- **BE**: Google Apps Script (GAS) - **Controller-Service 아키텍처**.
    - **패키지 구조**: `main` (운영 코드), `tests` (검증 코드) 분리.
    - **인증**: 카카오 고유 ID 연동 및 이메일 스마트 매칭.
- **DB**: Google Sheets (Schema 기반 타입 관리).

## 3. 아키텍쳐 & 디자인 시스템

### 3.1. 프론트엔드 (Admin WebApp)
- **SPA (Single Page Application)**: 매끄러운 탭 전환 및 전역 상태 관리(`useStore`).
- **데이터 캐싱**: 탭 진입 시 불필요한 서버 호출을 차단하고 초기 1회 로드로 최적화.
- **인디고(Indigo) 디자인**: 통일된 테마와 반응형 레이아웃(Desktop/Mobile).
- **사용성 보강**: 모달 활성화 시 부모 창 스크롤 차단 및 위치 보존 로직 적용.

### 3.2. 백엔드 (GAS - Controller-Service)
- **Router (`Api.js`)**: `doGet`(웹앱), `doPost`(챗봇 웹훅) 요청 라우팅 및 공용 로깅 엔진.
*   **Controllers**:
    *   `WebAppController`: 관리자 페이지 전용 API (`google.script.run`).
    *   `KakaoController`: 카카오 챗봇 스킬 전용 JSON 응답 처리.
- **Services**:
  - `MemberService`: 회원 CRUD 및 **스마트 매칭(이모지 제외 이름/이메일)** 지원.
  - `WorkoutService`: 주간 성적 관리 및 **슈퍼패스 월 1회 제한** 비즈니스 룰 강제.
  - `WorkoutLogService`: 개별 상세 운동 기록 및 배치 저장.
  - `KakaoService`: 챗봇 시나리오 및 사용자 등록/인증 관리.
  - `MigrationService`: 시트 스키마 자동 관리 및 **날짜/시간 포맷 표준화**.

### 3.3. 테스트 프레임워크
- **모듈형 수동 테스트**: `src/backend/tests/` 내에서 개별 서비스/컨트롤러의 기능을 수동으로 안전하게 검증 (Sandbox 방식).

## 4. 상세 기능 정의

### 4.1. 카카오 챗봇 (User Interface)
- **사용자 등록**: 챗봇 하단 메뉴를 통해 이메일을 입력하여 시스템 멤버와 카카오 계정 연동.
- **수동 인증**: 사진 없이 버튼 선택만으로 오늘의 운동 종류와 시간을 기록.
- **리더보드 공유**: 인증 완료 시 현재 주차의 전체 멤버 성적을 카톡방 복붙용 텍스트로 생성.
- **이미지 인증 (준비 중)**: 타임스탬프 사진 OCR 분석을 통한 자동 기록 기능.

### 4.2. 대시보드 (Admin Dashboard)
- **주차/연도 선택**: 대시보드 상단에서 특정 기간을 선택하여 과거 데이터 및 랭킹 조회.
- **레이블 표준화**: `5-1주차`, `2026 Q2 분기` 등 하이픈 기반의 직관적인 기간 표기.
- **랭킹 및 통계**: 선택한 주차/분기 기준 실시간 랭킹 및 운동 패턴 그래프 제공.

### 4.3. 운동 기록 관리 (Workout Records)
- **이중 검증**: 프론트/백엔드 모두에서 슈퍼패스 중복 사용 및 정책 위반 감지.
- **요약 바**: `총원 | 환급대상 (목표/슈퍼패스) | 미달성` 형식의 압축된 통계 제공.

## [부록] 주삼오공 회칙 요약 (시스템 적용 기준)
1. **인증 성공 조건**: 주 3회 이상 인증 완료 시 환급 대상.
2. **슈퍼패스 정책**: **월 1회(해당 주차의 월 기준) 사용 가능**. 0회 인증 시에는 사용 불가.
3. **리워드 산출**: 분기별 누적 성공 주차 및 총 인증 횟수를 기준으로 우수 활동자 선발.
