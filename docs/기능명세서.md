# 주삼오공 (운동인증방) 관리 시스템 기능 명세서

## 1. 개요
- **목적**: 온라인 운동인증 모임 회원 및 인증현황 관리 및 챗봇 API 서버
- **플랫폼**: Google Workspace (Google Sheets + Google Apps Script).
- **접근 권한**: 나 (관리자)

## 2. 기술 스택
- **FE**: Vue.js 3 (Composition API), Tailwind CSS, Phosphor Icons, **Element Plus**, **Chart.js**.
- **BE**: Google Apps Script (GAS).
    - **필수 추가 서비스 (Advanced Services)**: `Google Sheets API`, `GAS JWT lib`
- **DB**: Google Sheets.

## 3. 아키텍쳐 & 디자인 시스템

### 3.1. 프론트엔드 전략
- SPA (Single Page Application) 형태로 구성.
- **인디고(Indigo) 디자인 시스템**: 전 메뉴에 걸쳐 통일된 인디고 테마 헤더, 화이트 카드 레이아웃, 둥근 컨테이너(rounded-3xl) 디자인 적용.
- **3단계 Sticky 레이아웃**: GNB(상단바) > 페이지 타이틀 > 리스트 헤더 순으로 순차적 고정 레이어 구축.
- **상호작용 표준화**: 모든 모달에 ESC 키 닫기, 외부 클릭(Backdrop) 방지, '닫기' 버튼 명칭 및 스타일 통일 적용.

### 3.2. 백엔드 (GAS) 로직
- **주요 서비스**:
  - `Util`: 공통 유틸리티 (UUID, 안전한 날짜 파싱, 시트 객체 변환 및 산화 방지)
  - `MigrationService`: 시트 스키마 자동 관리 및 타입 강제
  - `MemberService`: 회원 CRUD 및 상태 관리
  - `WorkoutService`: 주간 운동 요약(횟수, 슈퍼패스, 메모) 관리
  - `WorkoutLogService`: 개별 상세 운동 기록 처리 및 **배치(Batch) 저장 API**
  - `RewardService`: 상금 지급 내역 관리
  - `SystemLogService`: 전역 자동 로깅 및 감사 추적

### 3.3. 데이터베이스 (Google Sheets)
- **`member`**: ID, 이름, 이메일, 활성화 여부, 가입일.
- **`workout_records`**: 주차별 인증 횟수, 슈퍼패스 사용 여부, 주차별 메모.
- **`workout_logs`**: 개별 운동 일시, 종류, 시간(분).
- **`rewards_log`**: 상금 지급 대상, 기간, 금액, 상세 내용.
- **`logs`**: 시스템 작업 이력 및 에러 데이터 (JSON 포함).
# 주삼오공 (운동인증방) 관리 시스템 기능 명세서 (V1.2.0)

## 4. 상세 기능 정의 (완료 항목)

### 4.1. 관리자 보안 (Security)
- **인증 게이트**: 앱 진입 시 4자리 PIN 번호 입력 필수. 인증 전 데이터 블러(Blur) 처리로 정보 보호.
- **서버 측 검증**: PIN 정보를 소스코드에 하드코딩하지 않고 구글 서버(`PropertiesService`)에서 안전하게 검증.
- **PIN 동적 관리**: 시스템 설정 모달을 통해 관리자가 직접 PIN 번호를 변경 가능.

### 4.2. 대시보드 (Dashboard)
- **종합 통계**: 활동 회원, 주간 인증 수, 누적 상금액 실시간 요약.
- **입체적 데이터 분석**:
  - **분기 누적 성적 (Line)**: 멤버별 성장 궤적 시각화 (직선 그래프, 현재 주차까지만 표시).
  - **선호 운동 종류 (Doughnut)**: 활동 로그 분석을 통한 종목별 인기 비중 분석.
  - **요일별 집중도 (Bar)**: 전체 기간의 요일별 활동 분포 분석.
- **인터랙티브 시각화**: 범례 클릭 시 특정 멤버 선 강조(Highlight)/디밍(Dim) 기능.
- **랭킹 시스템 (TOP 3)**:
  - **공동 순위 반영**: 횟수가 같을 경우 동일 순위 부여 및 하위 순위 자동 생략.
  - **자동 등급 뱃지**: 분기 성공률에 따라 **전설(90%↑), 열정(70%↑), 성실(50%↑)** 뱃지 부여.
- **스크린샷 저장**: 캡처 버튼(카메라 아이콘)을 통해 대시보드 요약 정보를 고화질 PNG 이미지로 저장 가능. (html2canvas 연동)
### 4.3. 회원 관리 (Members)
- **검색 및 필터**: 이름/이메일 검색 및 비활성 회원 필터링.
- **회원 활동 이력**: 모달 내 '활동 이력' 탭을 통해 개인별 분기 성공률 및 리워드 이력 상세 조회.
- **데이터 추출**: 회원 목록 CSV 다운로드.

### 4.4. 운동 기록 관리 (Workout Records)
- **실시간 정산 요약**: 주차별 **총원 / 환급 대상 / 미달성** 인원 자동 집계.
- **정산 필터**: 전체 / 환급 대상 / 미달성 상태별 리스트 필터링으로 정산 업무 효율화.
- **고급 로그 에디터**: 24시간제 입력, 인라인 편집, 배치 저장, 중복 감지 뱃지 적용.
- **데이터 추출**: 주간 운동 보고서 CSV 다운로드.

### 4.5. 리워드 관리 (Rewards)
- **지급 요약**: 총 지급 건수 및 누적 상금액 실시간 요약 바 제공.
- **추천 엔진**: 분기 데이터를 분석하여 성적 우수자를 선별하고 지급 폼 자동 채우기 지원.
- **데이터 추출**: 리워드 전체 이력 CSV 다운로드.

### 4.6. 시스템 로그 (System Logs)
- **감사 추적**: 모든 데이터 변경 이력 자동 로깅 및 JSON 상세 뷰어 제공.
- **데이터 추출**: 전체 시스템 로그 CSV 다운로드.

## [부록] 주삼오공 회칙 요약 (시스템 적용 기준)
1. **인증 성공 조건**: 주 3회 이상 인증 완료 시 환급 대상.
2. **슈퍼패스 정책**: 주 1~2회 인증 시에도 슈퍼패스 사용 시 환급 대상 포함 (단, 0회는 불가).
3. **리워드 산출**: 분기별 누적 성공 주차 및 총 인증 횟수를 기준으로 우수 활동자 선발.
