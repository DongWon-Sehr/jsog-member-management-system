# 주삼오공 Admin 시스템 사용자 가이드 (V1.2.0)

본 문서는 고도화된 주삼오공 관리 시스템의 주요 기능 사용법과 운영 규칙을 설명합니다.

## 1. 시스템 접속 및 사용자 연동
### 1.1. 관리자 웹앱 접속
- 현재 보안 강화 작업 중으로, 인증 게이트가 일시적으로 제거되었습니다. URL 접속 시 바로 대시보드 진입이 가능합니다. (추후 Google 계정 인증 도입 예정)

### 1.2. 카카오 챗봇 사용자 등록
- 카카오톡 채널 하단 메뉴의 **[사용자 등록]**을 클릭합니다.
- 챗봇의 안내에 따라 시스템에 등록된 **이메일 주소**를 입력합니다.
- 인증 완료 메시지가 뜨면, 해당 카카오 계정이 시스템 멤버 정보와 자동으로 연결됩니다.

## 2. 대시보드 및 데이터 분석
### 2.1. 기간별 데이터 조회
- 대시보드 상단의 **연도/주차 선택기**를 사용하여 원하는 기간의 성적을 조회할 수 있습니다.
- 랭킹 및 그래프 데이터는 선택한 주차 및 해당 분기에 맞춰 실시간으로 업데이트됩니다.

### 2.2. 그래프 활용
- **분기 누적 성적**: `2026 Q2 분기`와 같이 명확한 기간 명칭이 표시됩니다.
- **필터링**: 그래프 하단의 멤버 이름을 클릭하면 해당 멤버의 데이터만 강조하여 볼 수 있습니다.

## 3. 카카오 챗봇 운동 인증
### 3.1. 수동 인증 방법
- 챗봇에 "인증" 혹은 "운동"이라고 입력합니다.
- **[✏️ 수동 입력]** 버튼을 선택한 후, 오늘의 운동 종목을 클릭합니다.
- 인증이 완료되면 현재 주차의 전체 멤버 성적 현황(리더보드)이 출력됩니다.
- 해당 메시지를 복사하여 오픈톡방에 공유하세요.

### 3.2. 슈퍼패스 사용 제한
- 슈퍼패스는 **한 달에 딱 1번(정해진 주차의 월 기준)**만 사용 가능합니다.
- 이미 해당 월에 슈퍼패스를 사용했다면, 챗봇이나 관리자 페이지에서 추가 등록이 차단됩니다.

## 4. 효율적인 기록 관리 및 정산
### 4.1. 주간 정산 현황
- **운동 기록** 탭 상단 요약 바에서 `총원 | 환급대상 (목표달성/슈퍼패스) | 미달성` 수치를 한눈에 확인하세요.
- 환급 대상자 중 몇 명이 슈퍼패스로 구제받았는지 디테일하게 파악할 수 있습니다.

### 4.2. 데이터 내보내기 및 로그
- 모든 데이터는 우상단 **다운로드 아이콘**을 통해 CSV 파일로 추출 가능합니다.
- 시스템의 모든 작업 이력은 **시스템 로그** 메뉴에서 투명하게 확인됩니다.

---
**운영 팁**: 데이터가 실시간으로 반영되지 않을 경우, 각 화면의 **새로고침(회전 아이콘)** 또는 브라우저의 **F5**를 눌러주세요.
