# 주삼오공 Admin 시스템 사용자 가이드 (v1.1.0)

본 문서는 고도화된 주삼오공 관리 시스템의 주요 기능 사용법과 운영 규칙을 설명합니다.

## 1. 시스템 접속 및 사용자 연동
### 1.1. 관리자 웹앱 접속
- 현재 보안 강화 작업 중으로, 인증 게이트가 일시적으로 제거되었습니다. URL 접속 시 바로 대시보드 진입이 가능합니다. (추후 Google 계정 인증 도입 예정)

### 1.2. 카카오 챗봇 사용자 등록
- 카카오톡 채널 하단 메뉴의 **[사용자 등록]**을 클릭합니다.
- 챗봇의 안내에 따라 시스템에 등록된 **이메일 주소**를 입력합니다.
- 인증 완료 메시지가 뜨면, 해당 카카오 계정이 시스템 멤버 정보와 자동으로 연결됩니다.

## 2. 대시보드 및 데이터 분석
### 2.1. 기간별 데이터 조회
- 대시보드 상단의 **연도/주차 선택기**를 사용하여 원하는 기간의 성적을 조회할 수 있습니다.
- 랭킹 및 그래프 데이터는 선택한 주차 및 해당 분기에 맞춰 실시간으로 업데이트됩니다.
- **전체 랭킹 확인**: 랭킹 카드 하단의 '전체 랭킹 더보기' 버튼을 누르면 전체 멤버의 랭킹을 볼 수 있습니다. 이번 주차 랭킹에는 운동을 하지 않은(0회) 활동 회원도 함께 표시됩니다.
- **슈퍼패스 표시**: 슈퍼패스를 사용한 멤버는 이름 옆에 뱃지가 붙습니다. 주차 랭킹은 `슈퍼패스`, 분기 누적 랭킹은 사용한 월(`4월`, `5월` 등)이 표시됩니다.
- **운동 기록 빠른 이동**: 대시보드에서 특정 주차를 선택한 상태로 '인증' 카드를 클릭하면, 운동 기록 탭에서도 해당 주차의 기록을 바로 확인할 수 있습니다.
- **주차 선택이 탭 사이에서 유지됩니다**: 대시보드와 운동 기록 탭은 같은 주차를 바라봅니다. 어느 쪽에서 주차를 바꾸든 상단 메뉴로 다른 탭에 갔다 와도 그 주차가 그대로 유지되며, 반대 방향(운동 기록 → 대시보드)도 동일합니다. 다른 연도의 주차를 선택했다면 운동 기록 탭의 연도 선택기도 함께 따라옵니다. 플래너 저장으로 그 주차가 사라진 경우에만 오늘이 속한 주차로 돌아갑니다.
- **리워드 빠른 이동**: '누적 리워드' 요약 카드를 클릭하면 리워드 관리 탭으로 바로 이동합니다.

### 2.2. 그래프 활용
- **분기 누적 성적**: `2026 Q2 분기`와 같이 명확한 기간 명칭이 표시됩니다.
- **필터링**: 그래프 하단의 멤버 이름을 클릭하면 해당 멤버의 데이터만 강조하여 볼 수 있습니다.
- **전체 선택/해제**: 차트 우측 상단의 토글 버튼으로 모든 멤버 그래프를 한 번에 강조하거나 흐리게 처리할 수 있습니다.

## 3. 카카오 챗봇 운동 인증
### 3.1. 수동 인증 방법
- 챗봇에 "인증" 혹은 "운동"이라고 입력합니다.
- **[✏️ 수동 입력]** 버튼을 선택한 후, 오늘의 운동 종목을 클릭합니다.
- 인증이 완료되면 현재 주차의 전체 멤버 성적 현황(리더보드)이 출력됩니다.
- 해당 메시지를 복사하여 오픈톡방에 공유하세요.

### 3.2. 휴식주간에는 인증이 되지 않습니다
- 오늘이 플래너에서 휴식주간으로 지정된 기간이면 챗봇이 인증을 받지 않고 해당 기간을 안내합니다.
- 휴식주간은 성적 집계 대상이 아니기 때문입니다. 다음 운동주차가 시작되면 평소대로 인증하시면 됩니다.

### 3.3. 슈퍼패스 사용 제한
- 슈퍼패스는 **한 달에 딱 1번(정해진 주차의 월 기준)**만 사용 가능합니다.
- 이미 해당 월에 슈퍼패스룰 사용했다면, 챗봇이나 관리자 페이지에서 추가 등록이 차단됩니다.

## 4. 효율적인 기록 관리 및 정산
### 4.1. 주간 정산 및 회원 관리
- **운동 기록 필터**: 상단 요약 바의 `총원`·`환급대상`·`미달성` 항목을 클릭(터치)하면 해당 상태만 골라 볼 수 있습니다. 한 번에 하나만 선택되며, 선택된 항목을 다시 누르면 전체 보기로 돌아옵니다. (기존 상태 필터 메뉴와도 연동됩니다.)
- **운동 기록 상세 모달**: 모바일 환경에서는 각 기록들이 한눈에 보기 편한 세로형 카드 형태로 자동 정렬되며, 개별 운동 종류/날짜/시간 등을 기기 제한 없이 자유롭게 추가, 수정 및 삭제할 수 있습니다.
- **날짜는 해당 주차 안에서만 선택**: 운동 기록 모달은 **상단에서 선택한 주차의 기록만** 다룹니다. 그래서 날짜 칸은 달력이 아니라 **그 주차의 날짜만 들어있는 선택 목록**(`07/22 (수)` 형식)입니다. 다른 주차의 날짜는 목록에 아예 없으므로 잘못 고를 수 없습니다.
    - 지난 주차의 기록을 뒤늦게 입력(백필)할 때는 **먼저 상단 주차 선택기에서 해당 주차로 이동한 뒤** 모달을 열어주세요. 앱을 열면 오늘이 속한 주차가 자동 선택되므로 특히 주의가 필요합니다.
    - 이렇게 하는 이유: 운동 로그는 입력한 날짜가 속한 주차에 저장되지만 목록의 `운동 횟수`는 모달을 연 주차에 기록됩니다. 예전에는 이 둘이 어긋나 "목록의 횟수는 올라갔는데 모달을 다시 열면 기록이 안 보이는" 현상이 생길 수 있었습니다.
- **슈퍼패스는 목록과 모달 두 곳에서 켤 수 있습니다**: 목록의 토글은 누르는 즉시 반영되고, 운동 기록 모달의 `슈퍼패스 적용` 토글은 로그·메모와 함께 저장할 때 반영됩니다. 모달에서는 사용할 수 없는 상황이면 토글이 잠기고 이유가 표시됩니다(인증 0회, 같은 달에 이미 사용). 로그를 추가하면 조건이 바로 다시 계산되며, 이미 켜둔 슈퍼패스는 언제든 해제할 수 있습니다.
- **가입 전 주차에는 멤버가 보이지 않습니다**: 운동 기록과 대시보드는 그 주차까지 가입한 멤버만 보여줍니다. 2024년 초기 주차를 보면 창립 멤버만 나오고, 나중에 합류한 멤버는 가입한 주부터 등장합니다. `총원` 숫자도 그 기준으로 계산되니 과거 주차의 달성률이 왜곡되지 않습니다. 주중에 가입한 멤버는 가입한 그 주부터 포함됩니다.
- **운동 횟수 자동 교정**: 목록의 `운동 횟수`는 이제 해당 주차에 실제로 저장된 로그 개수로 다시 계산됩니다. 과거에 횟수가 어긋난 주차가 있다면, 그 주차의 기록 모달을 열어 아무 항목이나 저장하면 올바른 값으로 자동 교정됩니다.
- **연간 주차 셋업**: 설정 아이콘(톱니바퀴)을 눌러 1년치 주차 정보를 한 번에 생성하거나 관리할 수 있습니다.
    - **연도·월·주차는 직접 정합니다**: 시작일이 전월 말일인 주를 다음 달 1주차로 잡거나, 첫 주를 휴식으로 두고 둘째 주를 운동 1주차로 부르는 식의 운영이 가능하도록 세 값 모두 수동 입력입니다. 처음 만드는 주차에는 목요일이 속한 달을 기준으로 기본값이 채워지니 필요할 때만 고치면 됩니다.
    - **휴식 체크를 껐다 켜도 주차 번호가 유지됩니다**: 휴식으로 지정해도 입력해둔 번호가 남아 있어, 다시 운동주간으로 되돌리면 원래 번호가 그대로 복원됩니다. 휴식주간에도 연도·월은 계속 수정할 수 있고 주차 번호 칸만 숨겨집니다.
    - **번호가 겹치면 저장이 막힙니다**: 같은 연·월에 동일한 주차 번호가 두 번 지정되면 해당 행이 붉게 표시되고 저장 버튼이 비활성화됩니다. 어느 주차의 기록인지 구분할 수 없기 때문이며, 번호를 정리하면 바로 저장됩니다.
    - **저장하면 그 해 전체가 다시 정리됩니다**: 저장 시 해당 연도 구간이 화면 내용 기준으로 재작성되므로, 과거에 잘못 남은 중복 주차가 있었다면 함께 정리됩니다. 다른 연도 데이터는 건드리지 않습니다.
- **휴식주간 표시 및 처리**: 플래너에서 설정한 휴식주간은 대시보드와 운동 기록 탭에 `휴식주간`으로 명확히 표시됩니다. 해당 주차에는 기록 오류를 방지하기 위해 운동 입력을 차단하고 챗봇 인증도 받지 않으며, 분기 성공률과 리워드 추천 계산에서도 제외됩니다. 이전/다음 주차 이동은 달력 시간 순서대로 자연스럽게 지원됩니다.
- **비활성 회원 조회**: 회원 관리 탭에서 '비활성 회원 포함'을 체크하여 중도 하차한 멤버의 정보도 확인 가능합니다.
- **회원 목록 순서**: 목록은 **가입일이 빠른 순**으로 정렬됩니다. 운동 기록 탭의 멤버 순서도 동일하므로 두 화면을 나란히 보며 확인할 수 있습니다. 가입일을 아직 입력하지 않은 멤버는 맨 뒤에 표시되니, 순서가 어색하면 해당 멤버의 가입일을 채워주세요.
- **가입일 입력**: 회원 카드를 눌러 `기본 정보` 탭에서 가입일을 직접 지정합니다. 예전에는 시스템에 등록된 시각이 가입일로 표시되어 실제 가입일과 달랐습니다. 신규 등록 시에는 오늘 날짜가 기본값으로 채워집니다.
- **환급 계좌 입력**: 같은 화면에서 은행과 계좌번호를 관리합니다. 주간 환급을 보낼 때 시트를 뒤지지 않고 목록에서 바로 확인할 수 있습니다.
    - 계좌번호는 **숫자만 저장**됩니다. `3333-01-1234567`처럼 하이픈이나 공백이 섞인 값을 붙여넣어도 자동으로 정리됩니다.
    - 은행 칸은 목록에서 고르거나 직접 입력할 수 있고, 목록에 없는 은행도 그대로 저장됩니다.
    - **은행 자동 입력**: 카카오톡에서 받은 `우리 1002-123-456789`처럼 **은행명이 붙은 문자열을 은행 칸이나 계좌번호 칸에 그대로 붙여넣으면** 은행과 계좌번호가 각각 알아서 채워집니다. `KB국민`, `카뱅`, `woori`, `toss` 같은 줄임말·영문도 인식하고, `우리은행`처럼 입력하면 저장 시 `우리`로 정리됩니다. 목록에 없는 은행명은 입력한 그대로 남습니다.
    - **번호만 붙여넣은 경우**에는 `3333`(카카오뱅크)·`1000`(토스뱅크)으로 시작할 때만 은행이 자동 입력됩니다. 계좌번호만으로 은행을 알아내는 공식 기준이 없고, 우리은행(`1002…`)처럼 앞자리가 비슷한 은행이 있어 잘못 넣는 것보다 비워두는 편이 안전하기 때문입니다. 나머지 은행은 직접 고르시거나 은행명이 붙은 문자열을 붙여넣으세요. 자동으로 채워진 값도 언제든 고칠 수 있습니다.
    - 목록에서 이메일·계좌가 비어 있으면 `미등록`으로 표시됩니다.

### 4.2. 리워드 지급 및 추천
- **리워드 추천 받기**: 리워드 관리 탭에서 '추천 받기' 버튼을 누르면 성적이 우수한 멤버를 시스템이 자동으로 분석하여 추천해 줍니다. 추천된 내용을 바탕으로 지급 내역을 즉시 등록할 수 있습니다.
- **리워드 수정/삭제**: 리워드 목록의 항목을 클릭하면 상세 모달이 열려 지급 대상·기간·금액·설명을 수정하거나 삭제할 수 있습니다. 금액은 입력 시 자동으로 천 단위 쉼표가 표시됩니다.
- **지급일자는 날짜로 입력합니다**: 예전에는 `2026-Q1` 같은 기간 라벨과 날짜를 같은 칸에 섞어 넣을 수 있어 정렬이 뒤섞였습니다. 이제 날짜 선택기로 실제 지급일(또는 발표일)을 넣고, 어느 분기인지는 설명란에 적습니다(`2026-Q1 우수 활동자 / 구매상품: 러닝화`).

### 4.3. 데이터 내보내기 및 로그
- 모든 데이터는 우상단 **다운로드 아이콘**을 통해 CSV 파일로 추출 가능합니다. 회원 관리 탭에도 검색창과 다운로드 버튼이 추가되었으며(v1.1.0), 내려받는 내용은 화면에 보이는 목록(검색·필터 적용 결과)과 동일합니다.
- **메모의 콤마와 줄바꿈이 보존됩니다**: 예전에는 컬럼이 밀리는 것을 막기 위해 메모·상세내용의 콤마를 공백으로 바꿔서 내보냈습니다. 이제 모든 값을 따옴표로 감싸므로 원문 그대로 나갑니다. 엑셀에서 열 때 줄바꿈이 포함된 셀은 행 높이가 커질 수 있는데, 그것이 원본입니다.
- 시스템의 모든 작업 이력은 **시스템 로그** 메뉴에서 투명하게 확인됩니다. 검색 및 상태 필터(성공/오류)를 사용하여 특정 이력을 빠르게 찾으세요.

### 4.4. 실시간 데이터 갱신 및 Optimistic UI
- **대기 없는 화면 전환**: 회원 등록/수정, 운동 로그 일괄 저장, 리워드 등록/삭제 시 서버의 처리를 무작정 기다리는 대신 화면 데이터를 즉시 반영(낙관적 UI)하여 멈춤 없는 조작감을 제공합니다.
- **모달 저장 후 즉시 닫힘**: 모든 모달은 저장하기 버튼을 누르면 즉시 닫히며, 백그라운드에서 API 통신이 이루어집니다. 닫기 버튼과 ESC 키는 항상 눌러 사용할 수 있습니다.
- **옅은 노란색 하이라이트 효과**: 새로 추가된 항목(신규 회원, 신규 리워드)은 생성되는 순간 옅은 노란색으로 강조되었다가 약 2초에 걸쳐 서서히 페이드아웃 처리됩니다.
- **회원 변경 즉시 반영**: 회원을 추가하거나 비활성화하면 대시보드 및 운동 기록 등 전체 화면에 즉시 반영됩니다. (별도 새로고침 불필요)
- **오류 자동 복구 (롤백)**: 서버 측의 문제로 일시적 API 오류 발생 시, 반영되었던 임시 데이터들은 즉시 이전 상태로 롤백(복원)되며 경고 다이얼로그가 팝업됩니다.
