# 주삼오공 Admin 시스템 사용자 가이드 (V1.1.0)

본 문서는 고도화된 주삼오공 관리 시스템의 주요 기능 사용법과 운영 규칙을 설명합니다.

## 1. 시스템 보안 및 접속
### 1.1. 관리자 인증 (PIN)
- 앱 실행 시 가장 먼저 4자리 PIN 번호 입력 화면이 나타납니다.
- **초기 PIN**: `0000`
- 올바른 PIN을 입력해야만 내부 데이터를 열람하고 관리할 수 있습니다.

### 1.2. PIN 번호 변경
- 우상단 헤더의 **설정(톱니바퀴 아이콘)** 버튼을 클릭합니다.
- '시스템 설정' 모달에서 새로운 4자리 번호를 입력하고 '변경 완료'를 누릅니다.
- 변경된 PIN은 즉시 서버에 반영됩니다.

## 2. 대시보드 활용 (데이터 분석)
### 2.1. 랭킹 시스템
- **주간/분기 랭킹**: 인증 횟수가 높은 순으로 Top 3를 표시합니다.
- **공동 순위**: 횟수가 같으면 같은 등수를 부여합니다. (예: 1등이 3명이면 2, 3등은 표시되지 않음)
- **성취 등급 뱃지**: 분기 성공률(목표 달성 주차 비율)에 따라 자동으로 뱃지가 부여됩니다.
    - **전설**: 90% 이상 / **열정**: 70% 이상 / **성실**: 50% 이상

### 2.2. 인터랙티브 그래프
- **분기 누적 성적**: 주차별로 쌓여가는 인증 횟수를 직선 그래프로 보여줍니다.
- **하이라이트 기능**: 하단 범례의 **멤버 이름을 클릭**하면 해당 멤버의 선만 두껍게 강조되고 나머지는 흐려집니다. 많은 인원 중 특정 멤버를 추적할 때 유용합니다.
- **현재 주차 제한**: 아직 오지 않은 미래 날짜의 그래프는 그려지지 않아 데이터 왜곡을 방지합니다.

## 3. 효율적인 기록 관리 및 정산
### 3.1. 주간 정산 (Workout Records)
- **정산 필터**: 상단 '전체 상태' 필터를 통해 **[환급 대상]** 인원만 따로 모아볼 수 있습니다.
- **실시간 요약**: 헤더 하단에 이번 주 환급 대상자와 미달성자 수가 즉시 집계됩니다.

### 3.2. 정밀 로그 에디터
- 회원 행을 클릭하여 상세 로그를 관리합니다.
- **24시간제 입력**: 시/분 선택기를 통해 정확한 운동 시간을 기록합니다.
- **배치 저장**: 여러 건을 추가/수정한 후 '일괄 저장'을 누르면 한 번에 서버에 기록됩니다.
- **중복 감지**: 동일 날짜/시간에 데이터가 중복 입력되면 **!** 뱃지가 표시되며 저장이 차단됩니다.

## 4. 리워드 지급 자동화
### 4.1. 지급 대상 추천
- 리워드 관리의 **'추천 받기'**를 누르고 대상 분기를 선택합니다.
- 시스템이 달성률과 횟수를 분석하여 우수 활동자를 추천합니다.
- '선택' 버튼을 누르면 **지급 등록 폼에 사유와 금액이 자동 채워져** 매우 빠르게 등록 가능합니다.

## 5. 데이터 보존 및 감사
### 5.1. CSV 내보내기 (Export)
- 회원 목록, 주간 리포트, 리워드 내역, 시스템 로그 등 모든 메뉴의 우상단 **다운로드 아이콘**을 통해 엑셀 호환 CSV 파일을 내려받을 수 있습니다.
- 한글 깨짐 방지(BOM) 처리가 되어 있어 엑셀에서 바로 열어 활용 가능합니다.

### 5.2. 시스템 로그 (Audit)
- 시스템의 모든 변경 이력은 '로그' 메뉴에 자동 기록됩니다.
- 문제가 발생했을 때 상세 내역을 클릭하여 원천 JSON 데이터를 확인할 수 있습니다.

---
**운영 팁**: 데이터가 꼬이거나 최신 정보가 보이지 않을 경우, 각 화면의 **새로고침(회전 아이콘)** 또는 브라우저의 **F5**를 눌러주세요.
